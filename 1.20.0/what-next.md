# What’s next?

Congratulations! You have completed all the steps in the Get started guide.

Prepare the cluster for real use:

- Create a separate user for your application, so that it doesn’t connect as `root`. See [Create users in the Custom Resource](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/users.html#create-users-in-the-custom-resource)
- Back up on a schedule. See [Make scheduled backups](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/backups-scheduled.html)
- Learn how encryption and certificates work in [Transport Layer Security (TLS)](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/TLS.html)
- Understand what the Operator does and what stays with you. See [Design and architecture](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/architecture.html)

You also have the following options to move forward with the Operator:

- Deepen your monitoring insights by setting up [Kubernetes monitoring with PMM](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/monitor-kubernetes.html)
- Control Pods assignment on specific Kubernetes Nodes by setting up [affinity / anti-affinity](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/constraints.html)
- Ready to adopt the Operator for production use and need to delete the testing deployment? Use [this guide](https://docs.percona.com/percona-operator-for-xtradb-cluster/1.20.0/delete.html) to do it
- You can also try operating the Operator and database clusters via the web interface with [OpenEverest](https://openeverest.io/documentation/current/index.html) - an open-source web-based database provisioning tool based on Percona Operators. See [Get started with OpenEverest](https://openeverest.io/documentation/current/quick-install.html) on how to start using it
